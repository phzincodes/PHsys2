# Contribuir

Leia AGENTS.md, docs/STATUS.md e docs/BACKLOG.md. Use código novo .NET 10; não copie motores antigos nem execute conteúdo de posts. Faça alterações pequenas com testes que verificam comportamento e proteções, não apenas a existência de classes.

Valide restore, build, test e publish conforme AGENTS.md. Para testes de limpeza, use somente pastas temporárias exclusivas; não use arquivos pessoais. Para drivers/helper, use simuladores e depois VMs autorizadas. Não publique dados reais, segredos ou snapshots em logs/Issues/commits.

Documente implementado, testado e pendente separadamente. Teste ignorado por falta de serviço não é aprovação. Assets exigem licença/proveniência; não gerar artes/fotos automaticamente. Sem licença de redistribuição geral definida, a publicação pública continua pendente de decisão do proprietário.

Repositório remoto, branches protegidas, reviewers, canal de segurança e workflow Pages serão configurados quando o proprietário autorizar e identificar a conta/organização. Nunca invente identidade Git do usuário.
