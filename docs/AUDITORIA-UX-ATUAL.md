## O que já funciona e será preservado

SnapshotStore/ScanCoordinator compartilham uma análise; SQLite possui migração/retenção; cancelamento, falhas parciais e ausência de score falso têm testes. Cleanup possui prévia e exclusão restrita por handle. A API usa Identity real, PBKDF2, email configurável, TOTP/antirreuso, cookies seguros, CSRF, rate limits e autorização no servidor. Segurança HTTP é testada com Identity e SQLite/email de teste, não é login simulado de produção. PostgreSQL real continua dependente de configuração.

Escolha para a comunidade: a implementação atual é WPF nativa consumindo API; somente Admin/site são web. Manter WPF nativa evita duplicar autenticação e inserir tokens em JavaScript. WebView2 não é necessário para transformar o feed em ambiente integrado; reavaliar se houver frontend web compartilhado real.
