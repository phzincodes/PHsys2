# Frontend web Red Eclipse

Fontes buildless consumidas pelo ASP.NET Core existente. Execute o Compose provisionado e abra https://localhost:5178/. Não abrir index.html via file:// para fluxos autenticados: API/cookies/CSRF são same-origin. Confira docs/WEB.md, docs/EMAIL.md e docs/VALIDATION.md.

A landing não usa métricas fictícias. O painel vetorial do hero é identificado como representação conceitual, não screenshot de diagnóstico. Nenhuma arte/foto foi gerada. Não houve publicação Pages/Sites ou deploy externo. O fluxo local da skill Sites foi usado sem registro de projeto hospedado.
