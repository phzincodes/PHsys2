à primeira coleta.

Esta versão está em desenvolvimento. Execute os passos num Windows com SDK .NET 10. Nenhum backend é necessário para o diagnóstico local.

1. Abra o workspace

No VS Code, abra phsystem-next.code-workspace. O workspace desta máquina usa o SDK em D:. Em outro computador, ajuste os caminhos locais das tarefas.

2. Valide no Terminal Integrado

dotnet restore PHsystem.slnx
dotnet build PHsystem.slnx
dotnet test PHsystem.slnx
dotnet run --project src/PHsystem.Desktop

Você também pode usar Terminal → Executar Tarefa → restore, build, test ou desktop. Para depurar, use F5 com a configuração PHsystem Desktop.

3. Execute uma coleta

Use Iniciar diagnóstico. Aguarde as categorias; erros parciais ficam visíveis e não invalidam as demais. Drivers, recomendações e histórico usam o mesmo snapshot.

4. Revise antes de agir

Na limpeza, gere uma prévia e leia os arquivos elegíveis. A exclusão é permanente e exige uma escolha explícita. Não use versões de desenvolvimento para limpar dados sem backup.

5. Execute sem SDK

Um pacote self-contained local é gerado pelo comando abaixo. Abra PHsystem.Desktop.exe dentro da pasta completa; mantenha dependências e assets juntos.

dotnet publish src/PHsystem.Desktop -c Release -r win-x64 --self-contained true -o artifacts/desktop

Ainda não há release pública, assinatura ou instalador validado em máquina limpa. Backend e administração têm instruções separadas em docs/DEPLOYMENT.md.
